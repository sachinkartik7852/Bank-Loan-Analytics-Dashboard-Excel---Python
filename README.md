# Bank-Loan-Analytics-Dashboard-Excel---Python

 Bank Loan Analytics Dashboard | Excel & Python

📌 Project Overview

The Bank Loan Analytics Dashboard is a data analytics project
designed to analyze and visualize bank loan performance using Excel
and Python.

The project focuses on understanding loan applications, funded amounts,
repayments, loan status, interest rates, and borrower risk indicators.
The analysis transforms raw loan data into meaningful insights that can
support financial and business decision-making.

🎯 Project Objectives

Analyze overall loan application performance.

Track total funded amounts and repayments.

Compare Good Loan and Bad Loan performance.

Analyze loan status and repayment behavior.

Evaluate average interest rates.

Understand borrower risk using the Debt-to-Income (DTI) ratio.

Analyze loan performance across different loan purposes.

Create an interactive dashboard for quick KPI monitoring.

📊 Dashboard Analysis

1. Loan Application Analysis

The dashboard provides an overview of the total number of loan
applications and allows analysis of applications based on loan status
and purpose.

2. Good vs. Bad Loan Analysis

Loan applications are categorized into Good Loans and Bad Loans
to understand portfolio quality.

Good Loans: 86.18% of applications

Bad Loans: 13.82% of applications

This helps evaluate the overall health of the loan portfolio.

3. Funded Amount vs. Repayment

The dashboard compares the Total Funded Amount with the Total
Amount Received across different loan statuses, including:

Fully Paid

Current

Charged Off

4. Interest Rate Analysis

Average interest rates are analyzed according to loan status to identify
differences in lending risk and loan performance.

5. DTI Ratio Analysis

The Debt-to-Income (DTI) Ratio is analyzed across loan statuses to
understand borrower financial risk.

6. Loan Purpose Analysis

The dashboard provides filtering options for different loan purposes,
including:
